# Entry Check — дев-план MVP по фазам

Основа: «Entry Check — бизнес-план» и «Entry Check — план разработки MVP» (8 ноября 2026).
Работаем фазами. После каждой фазы — остановка, проверка и решение «дальше».

## Принципы, которые держим во всех фазах

- **Сервер делает только три вещи:** создаёт заказ, принимает колбэк оплаты, раз в день ставит дальние напоминания. Бесплатная проверка считается в браузере и не трогает сервер.
- **Только официальные ссылки.** Каждая `officialUrl` проходит автотест на домен из `data/official-domains.json`.
- **Правило без ручной проверки не попадает в продакшн.** ИИ готовит черновик, человек сверяет с первоисточником и ставит `verifiedAt`. Сборка для продакшна падает, если есть непроверенные правила.
- **Минимум данных:** гражданство, маршрут, даты, email. Номера паспортов не собираем.
- **Два трека:** `/ru` (СНГ, рубли, СБП) и `/en` (мир, евро). Тексты — только в `messages/{ru,en}.json`.
- **Бесплатные тарифы:** Cloudflare Workers + D1 + Cron, Resend, Cloudflare Web Analytics.

## Отклонения от исходного плана (и почему)

| Что | Было | Стало | Почему |
| --- | --- | --- | --- |
| Порядок | Лендинг (дни 2–3) → движок (дни 3–5) | Движок → лендинг | Живая карточка и образец результата на лендинге рендерятся движком; так лендинг сразу показывает настоящие данные |
| `cacheComponents` | Дефолт Next.js 16.4 | Выключен | Документация Next.js: Cache Components гарантирован только в Node.js-рантайме, а мы на Cloudflare Workers. Классическая статика + динамика проще и надёжнее с OpenNext |
| `proxy.ts` (дефолт Next.js 16) | — | `middleware.ts` на edge | Proxy в Next.js 16 работает только в Node.js, а OpenNext поддерживает это на Cloudflare экспериментально. Next.js сам советует оставаться на middleware ради edge. Предупреждение об устаревшем имени при сборке — ожидаемо |
| Кэш OpenNext | R2 по умолчанию | Static assets | ISR не нужен; R2 требует отдельной настройки |
| Плашки «Не государственный сайт» / «Не связаны с госорганами» | В шапке и подвале | Убраны (решение Данила, 8 ноября 2026) | Сервис даёт справку и никуда не регистрирует, поэтому это понятно и без плашки. Дисклеймер «справка, а не юридическая консультация» остаётся в подвале |

**Как сверять правило:** `npm run dev` → [localhost:3000/dev/rules](http://localhost:3000/dev/rules). Там матрица «что увидит путешественник» и карточки с первоисточником и официальной ссылкой. Если поле неверно — поправить JSON (путь указан у страны), затем нажать «Проверено»: в `verifiedAt` запишется сегодняшняя дата, `draftNote` удалится. В конце — `npm run check` и коммит.
